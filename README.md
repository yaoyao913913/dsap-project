# 實體卡牌對戰配對系統

## Proposal Report

### 動機與目標
實體卡牌玩家在遊玩時，常遇到找不到實力相近對手、時間難以配合，以及不確定適合對戰地點等問題。  
本專題目標為設計一套配對系統，依據玩家的牌位等級、卡牌類型、可遊玩時段與可接受店家，自動推薦最適合的對手與對戰地點，以提升配對效率與遊戲體驗。

### 預期功能
- 建立與管理玩家資料（名稱、等級、卡牌類型、可遊玩時段、可接受店家）
- 建立與管理店家資料（店名、地區、支援卡牌種類）
- 根據條件篩選玩家（等級範圍、卡牌類型、時間重疊）
- 推薦合適對手
- 推薦雙方皆可接受的店家
- 依配對分數排序推薦結果

### 使用技術
- C++
- 檔案儲存（CSV 或文字檔）
- 命令列介面（CLI）

### 時程規劃
- 第 1–2 週：設計資料結構（玩家與店家），完成基本資料輸入與儲存
- 第 3–4 週：實作條件篩選與配對邏輯
- 第 5–6 週：設計配對分數並加入排序機制
- 第 7 週以後：測試、優化與文件整理

### 與課程的關聯
本專題涉及多項資料結構與演算法概念：
- 使用 vector 儲存玩家與店家資料
- 使用 map 進行快速查詢與資料管理
- 使用 set 計算玩家之間可接受店家與時間的交集
- 使用排序（sorting）依配對分數排列推薦結果
- 設計配對評分演算法，用於衡量兩位玩家的適配程度  

透過這些資料結構與演算法，本系統能有效處理多條件配對問題，展現資料結構在實務應用中的價值。
